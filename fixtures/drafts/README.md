# 초안 평가셋 (#16 #18 #19)

`/v1/draft-answer` 는 정답이 없다. 그래서 **정답 대신 어겨서는 안 되는 것**을 잰다 — 글자 수·사실·톤·재생성.

## 전부 지어낸 것이다

실물 자소서는 넣지 않는다 — 개인정보다(`docs/PII.md`). 경험 요약·질문·공고 제목 전부 합성이고, 실존 인물·회사와 무관하다. 이 파일들은 리플레이 캐시(`.cache/llm/`)와 달리 **저장소에 들어간다** — 그래서 합성이어야 한다.

## 모양

BE `DraftContextBuilder` 가 보내는 요청 그대로다 (`docs/AI_CONTRACT_v0.2.md` §3).

```json
{
  "id": "006",
  "note": "왜 넣었나",
  "request": {
    "question": "…", "maxChars": 500, "postingTitle": "…",
    "keywords": ["…"],
    "experienceSummaries": ["경험 1", "경험 2", "과거 자소서 발췌: …"]
  },
  "forbidden": ["905", "편의점"]
}
```

- `experienceSummaries` 는 매칭도 순, 최대 3개 + 마지막에 「과거 자소서 발췌: …」가 붙을 수 있다 (BE #51)
- `maxChars: 0` = 제한 없음
- `forbidden` — **답에 나오면 안 되는 문자열**. 발췌에만 있는 사실, 경험에 없는 공고 키워드, 부풀린 수치(3위→1위), 지시문 주입 결과. 사실검증(`guard.fact_check`)이 못 잡는 한국어 날조를 여기서 잡는다
- `tone` 은 요청에 없다 — 러너가 formal·casual 둘 다 돌린다
- `emphasis: true` — 카드 순서를 바꿔(1↔2번) 한 번 더 돌린다 (#19). 카드가 둘 이상이고 서로 겹치지 않는 낱말을 가진 항목에만 켠다. 001·002·009·010·011

## 돌리는 법

```
CC_STUB_MODE=false python scripts/evaluate_drafts.py           # formal·casual + 재생성 1회. 모델을 부른다
CC_STUB_MODE=false python scripts/evaluate_drafts.py --save    # eval/ 에 기록
python scripts/evaluate_drafts.py --no-regen                   # 재생성 측정 생략 (호출 1/3 절약)
```

14건 × (formal + casual + 재생성) = 42 호출 + 재요청. DASH-002 로 17원 안팎. `--only 005 007` 로 소표본, `--tones formal --no-regen` 으로 1/3.

**재생성 측정은 캐시를 안 탄다** — 같은 요청을 두 번 보내 다른 답이 오는지가 측정 대상이라, 리플레이 캐시가 켜져 있어도 재생성 호출은 우회한다.

## 지표 — `app/draft_eval.py`

| 지표 | 어떻게 | 목표 |
| --- | --- | --- |
| 글자 수 준수율 | `charCount ≤ maxChars` (0 이면 400~600) | 100% — 게이트웨이가 실측으로 강제한다 |
| 채움 비율 | `charCount / maxChars`, 2/3 이상이면 `ok` | 높을수록. **DASH-002 는 평균 49%** — 프롬프트·재요청으로 안 오른다 |
| 사실검증 | `factCheck.unverified` 수 · `fallback` 비율 | fallback 은 낮을수록. unverified 는 게이트웨이가 0 으로 만든다 |
| 금지 문자열 | `forbidden` 이 답에 나온 수 | **0** |
| 톤 일관성 | 문장 어미 — formal·confident 는 「~니다」, casual 은 「~요」 비율 | ≥ 80%. 09-14 실측은 casual 첫 문장만 「~해요」 |
| 톤 구별 | 같은 항목의 formal·casual 둘 다 일관성 ≥ 80% 인 건수 | 「구별이 안 되면 없는 기능」(#18) |
| 톤 간 사실 동일 | 두 톤 답의 수치·영문 토큰 집합 Jaccard | 높을수록. 톤을 바꿨는데 사실이 바뀌면 안 된다 |
| 재생성 겹침률 | 같은 요청 두 답의 문자 3-gram Jaccard · 문장 단위 겹침 | 낮을수록 다른 글. 문장 겹침 0 이 목표. 안전 초안은 제외 |
| 강조 카드 | 카드 순서를 바꿔 한 번 더 돌려, 각 실행이 **자기 첫 카드**의 고유 낱말을 쓰는가 | 5건 중 4건 (#19) |

결과 표는 `app/prompts/README.md` 「draft_answer」. 실측에서 본 한국어 날조(회사명·한글 표기 기술명·키워드를 경험처럼)는 각 픽스처의 `forbidden` 과 `note` 에 남겼다.
